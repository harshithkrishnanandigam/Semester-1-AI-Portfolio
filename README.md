### ⚙️ Physics-Guided Reduced-Order ML for Fast Structural Deformation Prediction
**Computational Mechanics**

A project exploring the combination of **physics-based computational methods, reduced-order modeling, and machine learning** for efficient structural deformation prediction.

The project investigates concepts including **Finite Element Method (FEM), Singular Value Decomposition (SVD), reduced-order modes, and physics-guided machine learning**.
